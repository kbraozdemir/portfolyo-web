# Portfolyo Web Sitesi

Bu proje, React + TypeScript + Vite kullanılarak hazırlanmış minimal bir kişisel portfolyo sitesidir.

## Proje Hakkında

- Minimal ve modern bir kullanıcı arayüzü sunar.
- Projelerinizi "Problem / Çözüm / Uygulama" formatında sergilemek için tasarlandı.
- Responsive yapısı sayesinde masaüstü ve mobil cihazlarda iyi görünür.
- Hızlı yükleme ve sade stil ile profesyonel bir portfolyo deneyimi sağlar.

## Ana Özellikler

- Kısa tanıtım ve uzmanlık alanları
- Öne çıkan projeler için preview kartları
- Her proje için problem, çözüm ve uygulama açıklamaları
- İletişim bölümüne hızlı erişim

## Projeyi Çalıştırma

1. Proje klasörüne gidin:

```bash
cd /home/kubra/Belgeler/Proje/PortfolyoWeb/portfolyo-web
```

2. Gerekli paketleri yükleyin (ilk kez çalıştırırken):

```bash
npm install
```

3. Geliştirme sunucusunu başlatın:

```bash
npm run dev
```

4. Projeyi üretim için derleyin:

```bash
npm run build
```

5. Üretim derlemesini yerel olarak önizleyin:

```bash
npm run preview
```

## İçerik Düzenleme

- `src/App.tsx` dosyasında projelerin başlıklarını, açıklamalarını ve etiketlerini değiştirebilirsiniz.
- `src/App.css` dosyasında renkleri, kart düzenini ve responsive davranışı özelleştirebilirsiniz.
